📚 المستوى 1: التأسيس (درس 1 - 5)

الدرس 1: يعني ايه سايبر سكيورتي؟

السايبر سكيورتي معناه حماية كل حاجة على النت: موبايلك، حساباتك، صورك، فلوسك، ومواقع الشركات. تخيل ان الانترنت مدينة كبيرة، والهاكر حرامي بيلف فيها، وانت الشرطي اللي بيحمي المدينة. فيه 3 انواع هاكرز: الابيض بيحمي الشركات باذنها وبياخد فلوس، الاسود بيسرق من غير اذن، الرمادي بيعمل الاتنين. انت هتبقى الابيض المحترف.
❓ اسئلة: 1- يعني ايه سايبر سكيورتي؟ 2- ايه الفرق بين الابيض والاسود؟ 3- ليه الشركات بتدفع للهاكر الابيض؟

الدرس 2: ازاي تحمي نفسك 100%؟

عشان تبقى محترف لازم تبدأ بنفسك. اول حاجة: اعمل باسورد طويل 12 حرف فيه حروف وارقام ورموز زي @#$. تاني حاجة: فعل التحقق بخطوتين في واتساب وفيسبوك وجيميل. تالت حاجة: متدوسش على اي لينك يجيلك بيقولك كسبت جايزة او حسابك هيتقفل. رابع حاجة: متفتحش واي فاي عام في القهوة من غير حماية.
❓ اسئلة: 1- ليه مينفعش تستخدم نفس الباسورد لكل حساب؟ 2- ايه هو التحقق بخطوتين؟ 3- جالك لينك كسبت ايفون، هتعمل ايه؟

الدرس 3: ازاي الانترنت بيشتغل؟

لما بتكتب google.com، موبايلك بيروح لخادم اسمه DNS يسأله: فين مكان جوجل؟ الـ DNS بيرد عليه برقم اسمه IP زي عنوان البيت. بعد كده موبايلك بيبعت طلب للموقع، والموقع بيرد عليه بالصفحة. فهمك للحتة دي مهم لان كل الاختراق بيحصل في النص بين الطلب والرد.
❓ اسئلة: 1- ايه هو الـ IP؟ 2- ايه وظيفة الـ DNS؟ 3- ايه الفرق بين HTTP و HTTPS؟

الدرس 4: يعني ايه فيروس ومالوير؟

المالوير هو اي برنامج وحش. الفيروس بينتشر لوحده، التروجان بيستخبى جوه برنامج شكله حلو، والرانسوم وير بيقفل جهازك ويطلب منك فلوس عشان يفتحه. ازاي تحمي نفسك؟ متنزلش برامج من بره المتجر، وحدث موبايلك على طول، ومتفتحش ملفات غريبة.
❓ اسئلة: 1- ايه الفرق بين الفيروس والتروجان؟ 2- ايه هو الرانسوم وير؟ 3- لو موبايلك اتقفل وطلب فلوس، هتدفع ولا هتعمل ايه؟

الدرس 5: الهندسة الاجتماعية

اخطر طريقة اختراق مش بالكود، بالكلام. الهاكر بيكلمك ويعمل نفسه خدمة عملاء او صاحبك ويقولك ابعتلي الكود اللي جالك. 90% من الاختراقات بتحصل كده. القاعدة الذهبية: عمرك ما تبعت كود لحد، ولا باسورد، ولا صورة بطاقتك، مهما قالك هو مين.
❓ اسئلة: 1- يعني ايه هندسة اجتماعية؟ 2- واحد كلمك وقال انا من البنك هات الكود، هتعمل ايه؟ 3- ليه الطريقة دي اخطر من الكود؟

💻 المستوى 2: Linux والشبكات (درس 6 - 12)

الدرس 6: ليه بنستخدم Linux؟

كل المحترفين بيستخدموا Linux لانه مجاني، وسريع، وفيه كل ادوات الاختراق جاهزة. اشهر توزيعة اسمها Kali Linux. متخافش منه، هو زي ويندوز بس بتكتب اوامر بدل ما تدوس بالماوس. هتتعلمه من موبايلك عن طريق تطبيق Termux.
❓ اسئلة: 1- ليه المحترفين بيستخدموا Linux؟ 2- ايه هي Kali Linux؟ 3- ايه هو Termux؟

الدرس 7: اهم اوامر Linux

ls = اعرض الملفات اللي هنا. pwd = انت فين دلوقتي. cd = ادخل مجلد. mkdir = اعمل مجلد جديد. touch = اعمل ملف. rm = امسح. cat = اعرض اللي جوه الملف. احفظ الاوامر دي، هتستخدمها كل يوم.
❓ اسئلة: 1- اكتب امر عرض الملفات. 2- اكتب امر عمل مجلد اسمه hacker. 3- اكتب امر عرض اللي جوه ملف.

الدرس 8: اساسيات الشبكات

الشبكة زي عمارة. الـ IP هو رقم الشقة. الـ Router هو بواب العمارة. الـ Port هو باب الشقة. الـ Firewall هو الامن اللي واقف على الباب. لو الباب مفتوح، اي حد هيدخل. اشهر البورتات: 80 للمواقع العادية، 443 للمواقع الامنة، 22 للتحكم في السيرفر.
❓ اسئلة: 1- ايه هو البورت 80؟ 2- ايه وظيفة الـ Firewall؟ 3- شبه الـ Router بايه؟

الدرس 9: يعني ايه IP عام وخاص؟

الـ IP الخاص هو اللي جوه بيتك، زي 192.168.1.5. الـ IP العام هو اللي بيظهر للعالم كله لما تفتح النت. الهاكر لو عرف الـ IP العام بتاعك، يقدر يعرف مكانك التقريبي وشركة النت بتاعتك. عشان كده بنستخدم VPN يخفي الـ IP.
❓ اسئلة: 1- ايه الفرق بين العام والخاص؟ 2- ليه بنستخدم VPN؟ 3- لو حد عرف IP بتاعك، هيعرف ايه؟

الدرس 10: بروتوكولات مهمة

HTTP = بينقل البيانات من غير تشفير، اي حد يقدر يشوفها. HTTPS = بينقلها متشفرة، وده الامان. FTP = لنقل الملفات. DNS = بيترجم اسم الموقع لرقم IP. SSH = للتحكم في السيرفرات عن بعد بشكل امن.
❓ اسئلة: 1- ليه HTTPS امان اكتر من HTTP؟ 2- ايه هو SSH؟ 3- لو موقع بيطلب باسورد وهو HTTP، هتكتب باسوردك؟

الدرس 11: الواي فاي والاختراق

الواي فاي ليه انواع حماية: WEP قديم وسهل الاختراق، WPA2 قوي، WPA3 اقوى واحد. لو الراوتر بتاعك على WEP، غيره فورا. ومتخليش باسورد الواي فاي 12345678، اعمله قوي وطويل.
❓ اسئلة: 1- ايه اضعف حماية واي فاي؟ 2- ايه اقوى حماية؟ 3- ازاي تحمي الراوتر بتاعك؟

الدرس 12: اداة Nmap

Nmap هي عين المحترف. بتكشف اي جهاز على الشبكة واي بورت مفتوح فيه. مثال: nmap 192.168.1.1 هيقولك ايه البورتات المفتوحة في الراوتر. الاداة دي قانونية لو بتستخدمها على شبكتك انت، ممنوع على شبكة حد تاني من غير اذن.
❓ اسئلة: 1- ايه وظيفة Nmap؟ 2- هل ينفع استخدمها على شبكة جاري؟ 3- اكتب مثال امر Nmap.

🌐 المستوى 3: المواقع والبرمجة (درس 13 - 18)

الدرس 13: ازاي الموقع بيشتغل؟

الموقع ليه جزئين: Frontend اللي انت بتشوفه، معمول بـ HTML و CSS و JavaScript. و Backend اللي ورا الكواليس، معمول بـ PHP او Python وبيكلم قاعدة البيانات. الهاكر بيهاجم الاتنين، بس اغلب الثغرات في الـ Backend.
❓ اسئلة: 1- ايه هو Frontend؟ 2- ايه هو Backend؟ 3- فين اغلب الثغرات؟

الدرس 14: HTML للمحترفين

HTML هو هيكل الموقع. <h1> عنوان كبير، <p> فقرة، <img> صورة، <form> نموذج بياخد بياناتك. لو فهمت الـ form، هتفهم ازاي الهاكر بيسرق البيانات منه.
❓ اسئلة: 1- ايه وظيفة h1؟ 2- ايه وظيفة form؟ 3- اعمل صفحة فيها عنوان وصورة.

الدرس 15: JavaScript والثغرات

JavaScript هي اللي بتخلي الموقع يتفاعل معاك. المشكلة ان لو المبرمج سمح للمستخدم يكتب كود JavaScript في الموقع، الهاكر هيحقن كود خبيث. دي هي ثغرة XSS اللي هنشرحها بعد كده.
❓ اسئلة: 1- ايه وظيفة JavaScript؟ 2- ايه الخطر لو المستخدم كتب كود؟ 3- ايه هي ثغرة XSS؟

الدرس 16: قواعد البيانات SQL

قاعدة البيانات زي مخزن كبير فيه كل حسابات المستخدمين. لغة SQL هي اللي بتجيب البيانات منه. مثال: SELECT * FROM users معناها هات كل المستخدمين. الهاكر بيستغل SQL عشان يسرق كل الحسابات، ودي ثغرة SQL Injection.
❓ اسئلة: 1- ايه هي قاعدة البيانات؟ 2- ايه معنى SELECT؟ 3- ايه هي SQL Injection؟

الدرس 17: الكوكيز والجلسات

لما بتدخل فيسبوك، الموقع بيديك ورقة صغيرة اسمها Cookie فيها انك انت فلان. كل مرة تفتح فيسبوك، المتصفح بيوري الورقة دي للموقع. لو الهاكر سرق الورقة دي، هيدخل حسابك من غير باسورد. عشان كده لازم المواقع تشفر الكوكيز.
❓ اسئلة: 1- ايه هو الكوكيز؟ 2- لو اتسرق الكوكيز ايه اللي هيحصل؟ 3- ازاي تحمي الكوكيز؟

الدرس 18: تشفير البيانات

التشفير معناه تحويل الكلام العادي لكلام مش مفهوم غير للي معاه المفتاح. زي لما تبعت رسالة واتساب، محدش يقدر يقراها في النص غيرك انت واللي بعتله. اشهر انواع التشفير: AES و RSA.
❓ اسئلة: 1- يعني ايه تشفير؟ 2- ليه واتساب امن؟ 3- ايه هو المفتاح في التشفير؟

🔓 المستوى 4: الاختراق الاخلاقي (درس 19 - 24)

الدرس 19: جمع المعلومات

قبل اي اختراق، المحترف بيجمع معلومات 70% من الشغل. بيجيب اسم الشركة، الدومين، الايميلات، السيرفرات. ادوات: whois بيجيب بيانات الدومين، Google Dorking بيجيب ملفات متسربة من جوجل، theHarvester بيجيب ايميلات.
❓ اسئلة: 1- ليه جمع المعلومات اهم مرحلة؟ 2- ايه هو Google Dorking؟ 3- اكتب Dork يجيب ملفات PDF لموقع.

الدرس 20: ثغرة XSS بالتفصيل

تخيل موقع فيه مربع تعليقات. انت كتبت تعليق عادي، الموقع عرضه. الهاكر كتب في التعليق كود <script>alert(1)</script> والموقع عرضه ككود، فاشتغل عند كل الزوار وسرق الكوكيز بتاعتهم. الحل: الموقع لازم ينضف اي مدخلات قبل ما يعرضها.
❓ اسئلة: 1- اشرح XSS بالبلدي. 2- الهاكر بيستفيد منها في ايه؟ 3- ازاي المبرمج يحمي موقعه؟

الدرس 21: ثغرة SQL Injection

في صفحة الدخول، المفروض تكتب اسم وباسورد. الهاكر بيكتب في خانة الاسم: ' OR '1'='1. الجملة دي بتخلي قاعدة البيانات تفتكر انه ادمن وتدخله من غير باسورد. دي اخطر ثغرة وموجودة في مواقع كتير لحد دلوقتي.
❓ اسئلة: 1- اشرح SQL Injection. 2- ليه هي خطيرة؟ 3- ازاي تحمي موقعك منها؟

الدرس 22: ثغرة CSRF

تخيل انك فاتح حسابك في البنك، وفي نفس الوقت فتحت موقع خبيث. الموقع الخبيث بيبعت طلب للبنك من متصفحك من غير ما تحس، والبنك بيفتكر ان انت اللي طلبت. كده الهاكر بيحول فلوس من حسابك. الحل: المواقع لازم تطلب توكن سري مع كل طلب.
❓ اسئلة: 1- يعني ايه CSRF؟ 2- ليه لازم تكون فاتح حسابك عشان تشتغل؟ 3- ايه هو التوكن؟

الدرس 23: كسر الباسوردات

فيه طريقتين: Brute Force يعني تجرب كل الاحتمالات 0000 لحد 9999، و Dictionary Attack يعني تجرب قايمة باسوردات مشهورة زي 123456 و password. عشان كده لازم باسوردك يبقى طويل ومش متوقع. واداة John the Ripper بتستخدم لكده.
❓ اسئلة: 1- ايه الفرق بين Brute Force و Dictionary؟ 2- ليه باسورد 123456 خطر؟ 3- ايه هو باسورد قوي؟

الدرس 24: اختراق الواي فاي اخلاقيا

المحترف بيجرب يخترق الواي فاي بتاعه هو بس، عشان يتعلم يحميه. بيستخدم اداة aircrack-ng. لو باسورد الواي فاي ضعيف، هيتكسر في دقايق. لو قوي وطويل وفيه رموز، هياخد سنين. الدرس هنا: اعمل باسورد قوي.
❓ اسئلة: 1- هل ينفع تخترق واي فاي جارك؟ 2- ايه هي اداة aircrack؟ 3- ازاي تحمي الواي فاي بتاعك؟

💰 المستوى 5: Bug Bounty والشغل (درس 25 - 28)

الدرس 25: يعني ايه Bug Bounty؟

شركات زي جوجل وفيسبوك واوبر بتدفع فلوس لاي حد يلاقي ثغرة ويبلغهم. الثغرة ممكن تجيب 50 دولار وممكن 10000 دولار. هتبدأ من موقع HackerOne و Bugcrowd. هتعمل حساب، تختار شركة، تدور على ثغرات، وتبلغ. ممنوع تستغل الثغرة او تنشرها.
❓ اسئلة: 1- ايه هو Bug Bounty؟ 2- اذكر موقعين تشتغل عليهم. 3- لو لقيت ثغرة، اول حاجة تعملها ايه؟

الدرس 26: ازاي تكتب تقرير ثغرة محترف؟

التقرير المحترف فيه: 1- عنوان الثغرة. 2- خطوات اعادة الثغرة بالتفصيل. 3- فيديو او صور للثغرة. 4- تأثير الثغرة على الشركة. 5- اقتراح الحل. كل ما تقريرك كان واضح، كل ما الشركة دفعتلك اكتر وبسرعة.
❓ اسئلة: 1- ايه مكونات التقرير؟ 2- ليه لازم فيديو؟ 3- اكتب تقرير وهمي لثغرة XSS.

الدرس 27: ازاي تعمل CV وتشتغل؟

متكتبش في الـ CV انك بتعرف كل حاجة. اكتب: الثغرات اللي لقيتها، التقارير اللي كتبتها، الشهادات اللي خدتها، ومشروعك النهائي. اعمل حساب LinkedIn وانشر كل ثغرة تلاقيها. الشركات بتدور على اللي بيشتغل عملي مش اللي حافظ نظري.
❓ اسئلة: 1- ايه اهم حاجة في الـ CV؟ 2- ليه LinkedIn مهم؟ 3- هتكتب ايه في اول CV ليك؟

الدرس 28: الشهادات المهمة

اشهر شهادات: CEH للمبتدئين، OSCP للمحترفين ودي اقوى شهادة عملية، CompTIA Security+ للتأسيس. متجريش ورا الشهادات، اتعلم عملي الاول، الشهادة هتيجي بعدين وتزود مرتبك.
❓ اسئلة: 1- ايه هي شهادة OSCP؟ 2- ايه افضل شهادة للبداية؟ 3- الشهادة ولا العملي اهم؟

🛡️ المستوى 6: الدفاع والمشروع (درس 29 - 30)

الدرس 29: الدفاع - Blue Team

الدفاع مش انتي فيروس بس. لازم: جدار ناري قوي، تحديثات مستمرة لكل الاجهزة، نسخ احتياطي كل يوم، تدريب الموظفين انهم ميدوسوش على لينكات، ومراقبة الشبكة 24 ساعة بادوات زي Wireshark. الـ Red Team بيهاجم، والـ Blue Team بيدافع، وانت لازم تفهم الاتنين.
❓ اسئلة: 1- ايه الفرق بين Red و Blue Team؟ 2- ليه النسخ الاحتياطي مهم؟ 3- ايه وظيفة Wireshark؟

الدرس 30: مشروع التخرج - المحترف 😎

مطلوب منك دلوقتي: 1- اختار موقع وهمي للتدريب زي DVWA. 2- اعمل جمع معلومات كامل. 3- طلع 3 ثغرات على الاقل (XSS + SQL + CSRF). 4- اكتب تقرير كامل بالعربي والانجليزي. 5- صور فيديو 5 دقايق وانت بتشرح. التقرير والفيديو دول هما الـ CV بتاعك، وهما اللي هيشغلوك. مبروك يا محترف، انت كده خلصت الدورة.
